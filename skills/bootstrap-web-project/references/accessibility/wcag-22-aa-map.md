# WCAG 2.2 Level AA coverage map

This traceability map covers all WCAG 2.2 Level A and AA success criteria. It is
not a substitute for reading the normative standard or evaluating a product's
actual pages and states. WCAG 2.2 removed the obsolete criterion 4.1.1, so it is
intentionally absent.
